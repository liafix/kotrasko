# Public launch checklist

- [ ] Kotrasko confirms €10 / 60 min and the final schedule.
- [ ] Big Head House approves logo, name, and subdomain usage.
- [ ] Original full-resolution photos replace temporary screenshot crops.
- [ ] Final phone number and Kotrasko e-mail are added in Admin → Settings.
- [ ] Supabase migration is applied and production variables are set.
- [ ] A live Stripe Payment Link is created.
- [ ] Stripe post-payment redirect and webhook are configured.
- [ ] A real paid booking is smoke-tested and refunded if appropriate.
- [ ] Resend sending domain is verified.
- [ ] Privacy, booking, cancellation, no-show, and refund terms are approved.
- [ ] `DEMO_MODE=false`, strong admin password, and strong session secret are set.
- [ ] DNS/subdomain is connected and HTTPS is active.
- [ ] Mobile Safari and Android Chrome are tested on real devices.
